CLI entry commands

The Hypothesis Work Unit runtime is implemented and runnable from a checkout. These are the exact entry commands.

Implemented The commands below belong to the published runtime, not to the draft design. Artifact rendering and the checked-in tests use only the Python standard library.

Create a work unit

Give the exact ID, a title, and a working statement. This renders the durable Markdown artifacts for the unit inside the selected vault.

python3 code/hypothesis-work-unit/de.py --vault /path/to/vault new HY-001 --title "Title" --statement "Working statement"

Manage a work unit

Run the Manager entry for an existing unit.

python3 code/hypothesis-work-unit/de.py --vault /path/to/vault manage HY-001

Report the durable paths

Ask where the unit's files are, without starting anything.

python3 code/hypothesis-work-unit/de.py --vault /path/to/vault paths HY-001

Runtime requirements

Live workspace commands need more than Python:

  • Python 3.11 or newer;
  • Herdr, for live workspace commands;
  • Codex CLI, for the Dialogue role;
  • Claude Code, for the Worker role;
  • Obsidian, or the macOS open command, for note navigation.

Artifact rendering and the local tests use only the Python standard library. A command such as paths therefore works in a plain Python environment, while the commands that start live panes need the agent runtimes listed above.

Reading the output

The commands report durable paths rather than hidden session state, which is what makes the recovery procedure checkable: you can always ask the runtime where the files are and then read them yourself.
