Durable artifacts and human ownership

Durable Markdown files carry the meaning of a work unit. Runtime files carry only the current session, and can be thrown away.

Draft design The artifact boundary below belongs to the draft Hypothesis Work Unit design. The runtime that renders these Markdown files is implemented and covered by the repository tests.

Durable artifacts

Four kinds of file are durable. They are the conceptual authority for the unit:

  • HY-001.md — the Hypothesis definition, owned by the human.
  • Handoff.md — the current position and next action, so a cold start does not need chat history.
  • Review/RV-*.md — Review Packets for definition changes, pinned decisions, alternatives, and long evidence.
  • AGENTS.md — the instructions agents read before acting inside the unit.

Runtime files are not authority

Files under Runtime/ are reconstructable adapters. They record what the current live workspace happens to look like, and they can be recreated. They are explicitly not conceptual authority: nothing that matters should exist only there.

A useful test when reading a unit: if deleting a file would lose a decision, that file is durable. If deleting it would only cost you a restart, it is runtime.

What the human owns

The human owns checkbox completion and decisions. Agents maintain task wording and links so that the TODO stays readable and every item points at an exact heading, but agents do not silently approve or complete human work.

That single rule explains several details elsewhere in the design: why the workflow replay uses an intentional Command-click to complete a TODO instead of an automatic update, why completion history stays visible after an item is checked, and why a Review Packet exists at all. If an agent could complete human items, the durable files would stop being evidence of what the human actually decided.

When to open a Review Packet

Move work into an Obsidian Review Packet when it changes the Hypothesis definition, pins a decision, records alternatives, or carries long evidence. Short, reversible exchanges stay in Dialogue; anything that should still be legible next month belongs in Review/RV-*.md.
