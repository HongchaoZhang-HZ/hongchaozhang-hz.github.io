The normal human path

One ordinary pass through a work unit, described from the human's point of view. The workflow replay shows the same path as a recorded sequence.

Draft design This is the intended path in the draft Hypothesis Work Unit design, not a guarantee about a finished product.

Current capability The published Hypothesis Work Unit runtime and workflow replay use the Codex App as Manager. That is the implemented role mapping this page describes.

Next-stage target The bilingual user guide proposes Codex or Claude as the one Selected Manager, the single Active Manager of a Project, reached through shared Manager Adapters and a durable Handoff. That selection is a next-stage target, not implemented current Hypothesis behavior.

Step by step

  1. Propose the Hypothesis in Codex App. Give an exact ID, a title, and a working statement. The exact ID, such as HY-001, is what everything else will resolve against.
  2. Keep the same Codex task as Manager. The Manager task is the stable place to ask where things are, to recover after a restart, and to get the durable paths reported back.
  3. Use Herdr Dialogue for short exchanges. Bounded questions and corrections belong in Dialogue, where the Facilitator can record an answer without starting a long execution.
  4. Read the role-specific status. Each status pane is a projection for one role: shared state, review count, Human TODO, and links. Reading the pane is faster and more reliable than rereading a transcript.
  5. Navigate with Command-click and toggle TODO items intentionally. Links open the exact durable heading being discussed, and completion stays a deliberate human act.
  6. Move heavy material into an Obsidian Review Packet. Definition changes, pinned decisions, alternatives, and long evidence go to Review/RV-*.md rather than staying in a conversation.

Where each kind of work belongs

If the work is…It belongs in…
A short question or correctionHerdr Dialogue
Bounded execution against a stated boundaryHerdr Worker
Discovery, recovery, routing, or a status reportThe Codex App Manager task
A definition change, a pinned decision, alternatives, or long evidenceAn Obsidian Review Packet
Completing a human-owned checkboxThe human, deliberately

The path is designed so that no step depends on remembering the previous one. If you drop the thread, state and recovery describes how the unit is picked back up from durable files.
